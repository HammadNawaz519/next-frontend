1. CORE DESIGN PHILOSOPHY & DESIGN SYSTEM
================================================================================

Connect is designed as a hybrid of Apple iOS (HIG) minimalism and Instagram's 
rich media aesthetic, optimized for both desktop browsers and mobile screens 
(PWA / Android Capacitor).

Key Design Pillars:
- Glassmorphism & Depth: Layered blurs (`backdrop-blur-md` / `backdrop-blur-xl`), 
  translucent borders (`rgba(255,255,255,0.08)`), and soft drop shadows.
- Instant, Zero-Lag Hydration: Utilizes local device account storage to render 
  cached profile states instantly before server roundtrips finish, eliminating 
  blank layout flashes or jarring skeletons.
- Tactile Micro-Animations: Spring physics on button taps (`active:scale-95`), 
  double-tap heart bursts, clip-path story expansions, and smooth snap scrolling.
- Dual Theme Engine: Native Dark Mode (`#09090b` zinc background) and Clean 
  Light Mode (`#f8fafc` / `#ffffff`), with custom chat theme overrides.

3. APPLICATION FLOW & ROUTING STRUCTURE
================================================================================

/ (Root / Login)
  │
  ├── Unauthenticated ──► Shows Welcome Card & Authentication Bottom Sheet
  └── Authenticated   ──► Renders <DashboardPage /> inline for 0-latency launch
        │
        ├── View: 'home'   ──► <HomeFeed /> (Stories Bar + Feed Posts + Comment Drawer)
        ├── View: 'search' ──► Explore Grid (3-column Reels mosaic + Live User Search)
        ├── View: 'reels'  ──► <ReelsPlayer /> (Vertical fullscreen snap-scroller)
        └── View: 'chat'   ──► <SocialChat /> (Conversations + Realtime Chat + Themes)
              │
              ├── Slide-over ──► <ProfilePanel /> (User profile / Followers / Saved)
              ├── Fullscreen ──► <CallInterface /> (WebRTC Voice/Video Active Call)
              ├── Fullscreen ──► <AdminCamViewer /> (Admin Multi-cam Stream Monitor)
              ├── Route /accounts ──► Multi-Account Switcher & Meta Accounts Center
              └── Route /security ──► Password, 2FA, Active Sessions

--------------------------------------------------------------------------------
4.1. AUTHENTICATION & ONBOARDING (`app/page.tsx`)
--------------------------------------------------------------------------------
• Background:
  - Animated multi-color Grain Gradient Shader (`@paper-design/shaders-react`)
  - Translucent glass container with soft rounded corners (`rounded-3xl`).

• Views & Bottom Sheet States:
  1. Welcome / Intro Sheet:
     - Branding logo with glowing aura.
     - "Connect" typography with subtitle "A new way to talk, share and connect".
     - Primary "Log In" button and "Create New Account" secondary button.
     - Instant quick-switch avatar cards if previous accounts exist on device.
  2. Login Sheet:
     - Floating label inputs for Email / Phone / Username and Password.
     - Show/Hide password toggle icon.
     - "Forgot Password?" trigger link.
     - Continue with Google OAuth button with official Google emblem.
  3. Sign Up Sheet:
     - Multi-field form: Username, Full Name, Email, Phone Number, Password.
     - Realtime client-side validation badges.
  4. OTP Verification Sheet:
     - 6-box individual digit input with auto-advance and backspace focus shift.
     - Resend countdown timer (60s cooldown).
  5. Password Reset Sheet:
     - Email lookup -> 6-digit OTP verification -> New password confirmation.

5. MICRO-INTERACTIONS, HAPTICS & MOTION SYSTEM
================================================================================

• Haptic Feedback (`lib/haptics.ts`):
  - Integrates with Android / iOS device vibrator (`navigator.vibrate` / Capacitor).
  - Triggers on:
    * Tab switching: 'light' haptic (10ms).
    * Liking a post / reaction: 'medium' haptic (20ms).
    * Error / Alert: 'heavy' double haptic (40ms, 30ms).

• Motion & Transitions:
  - Spring-curve button scales: `active:scale-95 transition-transform`.
  - Floating Heart pop: `hf-heartPop` keyframe scaling from 0.4 to 1.3 with drop-shadow.
  - Bottom Sheet Slide: `cubic-bezier(0.25, 1, 0.5, 1)` easing.
  - Story Zoom: Coordinate-based clip-path expansion from circle to fullscreen.

6. RESPONSIVE DESIGN & MOBILE ADAPTATION (PWA / CAPACITOR)
================================================================================

• Adaptive Layout:
  - Desktop (>768px): Centered container max-w-lg or 2-column layout (Chat List 
    on left, Active Conversation on right).
  - Mobile (<768px): Fullscreen 100dvh viewport with bottom nav dock, safe-area 
    padding (`env(safe-area-inset-top)` / `env(safe-area-inset-bottom)`), and 
    native swipe-back gestures.

• PWA Capabilities:
  - Service Worker (`public/sw.js`) with cache-first strategy for static wallpapers, 
    audio files, avatars, and icons.
  - PWA Install prompt banner when accessed via mobile Safari / Chrome.
  - Web Push & Local Notifications for incoming calls and new chat messages.
